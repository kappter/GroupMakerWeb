# Skyline Yearbook Role Compass

Interactive, static Yearbook staff survey for GitHub Pages. No server, build step, package, account, or external library is required.

## Publish on GitHub Pages

1. Create a new GitHub repository or open an existing Yearbook tools repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Put the resulting GitHub Pages URL into Canvas as the Role Compass assignment link.

## Student submission

The site stores no responses on a server. At the end, students should use **Copy summary** and paste the result into a private Canvas assignment, or download the `.txt` result and upload it. Avoid asking students to post results in a public discussion.

## Scoring model

The six role scores combine current-skill self-ratings, situational role choices, and initial responsibility interests. Results are intentionally described as starting signals rather than placements or personality types.
